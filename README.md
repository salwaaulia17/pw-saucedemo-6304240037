[![Playwright Tests](https://github.com/salwaaulia17/pw-saucedemo-6304240037/actions/workflows/playwright.yml/badge.svg?branch=tugas-individu)](https://github.com/salwaaulia17/pw-saucedemo-6304240037/actions/workflows/playwright.yml)

## Deskripsi Proyek
Proyek ini merupakan implementasi otomasi pengujian aplikasi web SauceDemo menggunakan Playwright. Pengujian mencakup fitur login, belanja, keranjang, checkout, pengurutan produk, dan pengujian beberapa jenis pengguna.

## Teknologi yang Digunakan
- JavaScript
- Node.js
- Playwright Test
- Git dan GitHub
- GitHub Actions

## Browser yang Didukung
- Chromium
- Firefox
- WebKit

## Instalasi

1. Clone repository:
   ```bash
   git clone https://github.com/salwaaulia17/pw-saucedemo-6304240037.git
## Menjalankan Pengujian

Install dependencies:

npm install

Install Playwright browsers:

npx playwright install

Jalankan semua pengujian:

npx playwright test

Melihat HTML Report:

npx playwright show-report
